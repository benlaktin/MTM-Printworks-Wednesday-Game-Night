MTM Printworks Open Games Night

Open Games Night is available by signup almost every Wednesday. Tables are free to book, with game mats and terrain available for use.

Find an available table

Select a Wednesday and start time, then click View Available Tables.

Games can start after 4:30 PM and must start by 7:00 PM. Please select your planned start time when registering so other players and the store host can see when your game is expected to begin. Last turn is called at 9:45 PM, and the shop closes for gaming at 10:00 PM. If there are no Wednesday signups, the shop closes at its regular 6:00 PM time.
Past and future Wednesdays can be viewed.

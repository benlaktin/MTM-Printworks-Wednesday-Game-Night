MTM Printworks Open Games Night

Open Games Night is available by signup almost every Wednesday. Tables are free to book, with game mats and terrain available for use.

Reserve a table

Select a Wednesday and start time. The available-table list will update automatically using current Google Sheets reservations.

Games can start after 4:30 PM and must start by 7:00 PM. Each reservation lasts 2.5 hours. Last turn is called at 9:45 PM, and the shop closes for gaming at 10:00 PM. If there are no Wednesday signups, the shop closes at its regular 6:00 PM time.
Past and future Wednesdays can be viewed.
